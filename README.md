## 🧠 Key Architecture Cheat Sheets

### 1. The 4 Layers of Salesforce Security
```
┌─────────────────────────────────────────────────────────────┐
│  LAYER 1: ORGANIZATION LEVEL (The Front Gate)               │
│  "Can this user log in?" ──► Passwords, Login Hours, IP, MFA│
├─────────────────────────────────────────────────────────────┤
│  LAYER 2: OBJECT LEVEL (The Building Door)                  │
│  "What can they do with the table?" ──► CRUD Permissions    │
├─────────────────────────────────────────────────────────────┤
│  LAYER 3: FIELD LEVEL (The Filing Columns)                  │
│  "Which columns can they see?" ──► FLS (Visible, Read-Only) │
├─────────────────────────────────────────────────────────────┤
│  LAYER 4: RECORD LEVEL (The Filing Folders)                 │
│  "Which individual rows can they see?" ──► OWD, Roles, Rules│
└─────────────────────────────────────────────────────────────┘
```

### 2. The Record-Level Security Funnel
```
              [ ORGANIZATION-WIDE DEFAULTS (OWD) ]
                   Restrictive Baseline (Private)
                                │
                                ▼
                       [ ROLE HIERARCHY ]
                  Opens access vertically upward
                                │
                                ▼
                        [ SHARING RULES ]
                  Opens access laterally / across
                                │
                                ▼
                  [ MANUAL SHARING & TEAMS ]
                  Ad-hoc point-to-point sharing
                                │
                                ▼
                     [ RESTRICTION RULES ]
                 Further filters matching records
```

### 3. The 3-Word Sharing Mental Model
- 🤝 **Sharing Rule** = **GIVE** access beyond OWD.
- 🔒 **Restriction Rule** = **RESTRICT** access matching specific criteria.
- 🎯 **Scoping Rule** = **FOCUS** list views without revoking underlying access.
